Proposta de Integração - APIs Google Maps

Sistema de Rastreamento Veicular - Unifique
Data: 06 de Fevereiro de 2026

1. Resumo Executivo

Este documento apresenta uma análise de viabilidade para integração das APIs do Google Maps ao sistema de rastreamento veicular, considerando uma frota de 900 rastreadores com envio de dados a cada 30 segundos.

Objetivo: Avaliar quais APIs do Google agregam valor ao sistema sem comprometer o orçamento, mantendo a infraestrutura atual baseada em OSRM/OpenStreetMap para funcionalidades de alto volume.

2. Análise de Volume de Dados

Métrica Valor
Quantidade de rastreadores 900
Frequência de envio A cada 30 segundos
Posições por dia (por rastreador) 2.880
Total de posições por dia 2.592.000
Total de posições por mês 77.760.000

3. APIs Analisadas

3.1 Roads API (Limites de Velocidade)

Item Detalhe
Funcionalidade Limite de velocidade oficial das vias + snap-to-road
Preço Google $0,02 por consulta
Volume mensal 77.760.000 consultas
Custo mensal estimado ~$1.555.000 USD (~R$8.000.000)
Viabilidade INVIÁVEL
Conclusão: A Roads API não é viável para consultas em tempo real com este volume. O sistema atual com OSRM/OpenStreetMap (gratuito) deve ser mantido para esta funcionalidade.

3.2 Geocoding API (Endereços)

Item Detalhe
Funcionalidade Converter coordenadas GPS em endereços legíveis
Preço Google $5,00 por 1.000 requisições
Uso estimado ~30.000 requisições/mês (sob demanda)
Custo mensal estimado $150 USD (~R$750)
Viabilidade VIÁVEL

Casos de uso:

  • Exibir endereço nos detalhes do veículo
  • Relatórios de viagem com endereços de origem/destino
  • Histórico de paradas com localização
  • Notificações com endereço (ex: "Veículo parou em Rua XV de Novembro, 123")

3.3 Maps JavaScript API (Mapa Visual)

Item Detalhe
Funcionalidade Substituir mapa OpenStreetMap pelo Google Maps
Preço Google $7,00 por 1.000 carregamentos
Uso estimado ~5.000 carregamentos/mês
Custo mensal estimado $35 USD (~R$175)
Viabilidade OPCIONAL

Benefícios:

  • Visual mais familiar para usuários
  • Imagens de satélite mais atualizadas
  • Street View integrado

4. Recomendação

API Recomendação Custo/Mês
Geocoding API SOLICITAR ~R$750
Maps JavaScript API OPCIONAL ~R$175
Roads API NÃO SOLICITAR Inviável

Investimento Mensal Recomendado

R$ 750 a R$ 925

6. Solicitação ao Google Cloud

APIs a serem habilitadas:
  • Geocoding API - Conversão de coordenadas em endereços
  • Maps JavaScript API - Exibição de mapas (opcional)

Informações necessárias:

  • Nome do projeto no Google Cloud
  • Chave de API (API Key) gerada
  • Restrições de domínio configuradas (rastreador.unifique.com.br)
