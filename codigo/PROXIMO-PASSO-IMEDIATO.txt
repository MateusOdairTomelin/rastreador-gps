🔍 SE NÃO ESTÁ FUNCIONANDO
═══════════════════════════════════════════════════════════════════════════════

❌ Nenhum packet 0x12 chegando?
──────────────────────────────────────────────────────────────────────────────

1. Verificar LED GPS
   [ ] Pisca sincronizado? (Indica tentativa de GPS)
   [ ] Não pisca? (GPS desabilitado ou sem antena)

2. Reenviar comando de ativação:
   # Via HTTP:
   curl http://localhost:8000/api/dispositivos/send-command \
     -X POST \
     -H "Content-Type: application/json" \
     -d '{"imei":"356354870699551","command":"#55555#YGPS#1#"}'

3. Aumentar delay entre comandos:
   # Em /server/index.js linha ~226:
   await new Promise(resolve => setTimeout(resolve, 3000)); // 3s

4. Verificar sinal de satélite:
   # Levar rastreador para área aberta, longe de árvores
   # Aguardar 2-3 minutos para GPS lock


❌ Packet chega mas coordenadas erradas?
──────────────────────────────────────────────────────────────────────────────

1. Verificar CRC (se mostra warning)
   grep "CRC" nohup.out

2. Validar fórmula no parser:
   node teste-parser-validation.js
   # Deve mostrar "✅ VÁLIDO"

3. Se fórmula errada em /server/parsers/gps-parser.js:
   # Procurar por: / 1800000
   # Não deve estar como: / 30000


❌ Dados chegando mas não salvando no DB?
──────────────────────────────────────────────────────────────────────────────

1. Verificar database conectada:
   # Verificar .env
   DATABASE_URL="..."

2. Verificar modelo de dados em prisma/schema.prisma
   [ ] Tabela "localizacoes" existe?
   [ ] Campos corretos: latitude, longitude, velocidade, etc?

3. Executar seed se necessário:
   node prisma/seed.js
